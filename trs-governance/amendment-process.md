# Amendment Process

1. Submit proposal using `proposal-template.md`.
2. Tag proposal as:
   - clarification,
   - profile addition,
   - normative behavioral change.
3. Open review window with evidence links.
4. Run conformance and interoperability impact analysis.
5. Vote/ratify per `voting.md`.
6. Record final outcome in:
   - `accepted/` or
   - `rejected/`.
