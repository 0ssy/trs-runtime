# Build your first application

Goal: consume TRS through the stack, without embedding runtime logic.

1. Start `trs-node`.
2. Use `trs-sdk-python` to submit/query records.
3. Optionally use `trs-cli` for manual testing and ops flows.
4. Keep app business logic outside runtime and node.

See [../examples/resource-allocation.py](../examples/resource-allocation.py) for a minimal flow.
